# Ajorithm

A Solana smart contract for rotating savings groups (Ajo) built with Anchor.

## Program Details

- **Program ID:** DNxjy5KkrdJsuf9NNRMcdEuiuME1yV9Rxb8ETLJyAV9f
- **Network:** Devnet
- **Anchor version:** 1.0.2

## Instructions

- `create_pact` — Initialize a new savings group
- `join_pact` — Join an existing pact
- `contribute` — Make a contribution
- `release_payout` — Release funds to the current recipient
- `update_reputation` — Update a member's reputation score

Located at `target/idl/ajorithm.json`
